# Customer Churn Prediction

A Machine Learning application that predicts whether a telecommunications customer is likely to churn using customer demographics, account information, subscribed services, and billing details.

The project compares Logistic Regression and Random Forest classifiers, evaluates their performance, and deploys the selected model through an interactive Streamlit application.

## Live Demo

## Features

- Customer churn prediction using Machine Learning.
- Exploratory Data Analysis (EDA) and data preprocessing.
- Comparison of Logistic Regression and Random Forest.
- Hyperparameter tuning using RandomizedSearchCV.
- Model evaluation using Precision, Recall, F1-score and ROC-AUC.
- Feature importance analysis.
- Interactive Streamlit web application.
- Downloadable prediction reports in CSV and PDF formats.

## Model Performance

The tuned Random Forest model was selected as the final model based on its churn detection performance.

Test-set results at a classification threshold of 0.5:

| Metric | Score |
|---|---:|
| Accuracy | 76% |
| Precision (Churn) | 54% |
| Recall (Churn) | 76% |
| F1-score (Churn) | 63% |
| ROC-AUC | 0.8424 |

The model achieved higher recall than the Logistic Regression baseline, identifying more actual churn customers, although it also produced more false positives.

Download the dataset from:

Place `WA_Fn-UseC_-Telco-Customer-Churn.csv` in the project root directory to run the Jupyter Notebook and standalone model test script.

## Run Locally

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd customer-churn
```

### 2. Create and activate a virtual environment

```bash
python -m venv venv
```

Windows:

```powershell
venv\Scripts\activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the Streamlit application

```bash
streamlit run app.py
```

The application will open in your browser.
